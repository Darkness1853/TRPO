***Цель работы***

Разработка интерфейсных тестов для проверки функциональности библиотеки линейной алгебры OpenBLAS (CBLAS Level 2 операции).

***Задачи***

- Скачать и собрать дистрибутив OpenBLAS
- Создать интерфейсные тесты, покрывающие весь CBLAS Level 2 функционал
- Протестировать на одной ОС с поддержкой многопоточности
- Обеспечить покрытие всех типов аргументов и значений
- Продемонстрировать успешное прохождение тестов
- Показать полноту покрытия

***Ход работы***

1. Загрузка и сборка OpenBLAS
```
git clone https://github.com/OpenMathLib/OpenBLAS.git
cd OpenBLAS
```
2. Сборка библиотеки с поддержкой многопоточности
```
make -j4
make install PREFIX=/usr/local/openblas
```
3. Разработка тестов
   
Были разработаны интерфейсные тесты для групп функций CBLAS Level 2

4. Покрытие типов аргументов

Для каждого типа данных реализованы отдельные тесты:

s (float) - 8 тестов

d (double) - 8 тестов

c (complex float) - 7 тестов

z (complex double) - 7 тестов
